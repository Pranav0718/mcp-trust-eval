Methodology

Four-Layer Security Analysis

01
🔑
Secret Scanning

Detects hardcoded API keys, tokens, passwords, and private keys across 12 secret types including AWS, GitHub, OpenAI, Anthropic, and generic credentials. A single exposed credential can compromise your entire agent pipeline.

02
📦
Dependency CVEs

Queries the OSV vulnerability database for known CVEs in all Python and npm dependencies. Vulnerable packages in a connected server are a direct attack path into your agent, including the MCP SDK itself.

03
🎯
Tool Definition Analysis

The most MCP-specific check. Scans every tool name, description, and parameter definition for instruction override attempts, data exfiltration patterns, SSRF vectors, role hijacking, and dangerous function usage that could hijack agent behavior.

04
🏛
Trust Signal Analysis

Evaluates repository health including maintenance activity, security policy presence, license, community vetting, and archival status. An abandoned or unvetted repository will never receive security patches.

Intelligence

MCP Attack Classes Detected

Critical
Tool Poisoning

Hidden instructions embedded in MCP tool descriptions that hijack agent behavior when the tool is invoked. The agent follows the malicious instructions without the user's knowledge, potentially exfiltrating data or executing unauthorized actions.

Critical
Confused Deputy

A server that requests permissions beyond its stated purpose and uses them on behalf of a higher-privileged caller. Discovered in production AI agent OAuth 2.0 handshakes, enabling privilege escalation across interconnected SaaS tools.

High
Indirect Prompt Injection

Malicious instructions delivered through tool return values rather than direct user input. When an agent calls a tool and receives a poisoned response, the attacker gains control of the agent's next actions without ever interacting with the user.

High
DNS Rebinding

Exploits the MCP SDK's default lack of DNS rebinding protection to redirect agent traffic to internal network addresses, potentially reaching cloud metadata endpoints, internal APIs, or other restricted resources.

High
Credential Harvesting

Tools designed to extract API keys, tokens, or credentials from the agent's context window or environment. Hardcoded secrets in server source code create immediate exposure vectors for any agent that connects.

Medium
Rug Pull Attack

A server that behaves safely during evaluation but silently updates its tool definitions to include malicious instructions after being trusted and connected to a production agent. Abandoned repositories are especially susceptible to this if ownership changes.
